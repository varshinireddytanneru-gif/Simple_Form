# Simple Signup Form

A simple and beginner-friendly Signup Form created using **HTML and CSS**.

## 📌 About the Project

This project is a basic signup form designed to practice HTML form elements and CSS styling.

The form includes fields such as:
- Name
- College
- Email
- Submit button

It also includes basic form validation using HTML attributes such as `required` and `type="email"`.

## 🛠️ Technologies Used

- HTML5
- CSS3
